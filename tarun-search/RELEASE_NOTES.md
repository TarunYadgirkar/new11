## Download

| Your computer | File |
| --- | --- |
| Mac with Apple Silicon (M1–M4) | `Tarun-Search-…-mac-arm64.dmg` |
| Mac with Intel | `Tarun-Search-…-mac-x64.dmg` |
| Windows 10 / 11 | `Tarun-Search-…-win-x64.exe` |
| Linux | `Tarun-Search-…-linux-x86_64.AppImage` (or the `.deb` for Ubuntu/Debian) |

**First launch:** the apps aren't signed with a paid developer certificate, so your computer asks once.
- **Mac:** System Settings → Privacy & Security → **Open Anyway**.
- **Windows:** **More info → Run anyway**.

See the [README](https://github.com/tarunyadgirkar/new11/tree/main/tarun-search#readme) for everything Tarun Search can do, including its three mystery features 🎁.
